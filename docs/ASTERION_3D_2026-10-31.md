# Premier Asterion 3D — 31 octobre 2026

Le modèle Meshy remplace l’image de l’Asterion dans le rendu de combat local et distant. La coque est calculée en WebGL à chaque image, puis composée dans le canvas de combat existant. Ce premier essai conserve les déplacements sur le plan actuel.

## Utilisation

L’Asterion utilise automatiquement le modèle avec les réglages Haut et Moyen. Le réglage **Vaisseaux 3D (si disponibles)** permet de choisir l’affichage. Le préréglage Bas utilise l’image d’origine. Pendant le chargement, en cas d’erreur ou de perte du contexte graphique, l’image reste disponible.

Le moteur Three.js r187 et ses utilitaires sont livrés dans `vendor/three-r187/`, avec leur licence MIT. Le script de déploiement inclut ce dossier. Le chargement ne dépend d’aucun CDN ni d’un lien Meshy temporaire.

Le vol d’essai s’ouvre à `http://127.0.0.1:8765/tools/ship-3d/index.html` quand le projet est servi sur le port 8765. Il utilise le même rendu de vaisseau que le combat. Les modes **Piloter** et **Observer la coque** permettent de comparer la 2D et la 3D, de tourner autour et d’examiner le dessous. Ce vol libre n’enregistre aucune progression de compte.
